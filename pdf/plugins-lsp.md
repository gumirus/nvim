## <span class="blue">mason.nvim</span>

- <span class="green">Автоматическая установка LSP, форматтеров и линтеров</span>
- <span class="orange">Открой Mason:</span> <kbd>:Mason</kbd>

## <span class="blue">nvim-lspconfig</span>

- <span class="green">Настройка и запуск LSP-серверов</span>
- <span class="orange">Примеры хоткеев:</span>
  - <kbd>gd</kbd> — перейти к определению
  - <kbd>gi</kbd> — перейти к реализации
  - <kbd>K</kbd> — документация по символу
  - <kbd>&lt;leader&gt;ca</kbd> — code actions
  - <kbd>&lt;leader&gt;rn</kbd> — переименование

## <span class="blue">nvim-cmp</span>

- <span class="green">Современное автодополнение с поддержкой snippet'ов</span>
- <span class="orange">Tab</span> — выбрать/подтвердить автодополнение

---

## <span class="red">Лайфхаки</span>

- Можно настраивать автодополнение под любой язык
- LSP поддерживает форматирование, диагностику, подсказки
- Mason позволяет быстро устанавливать и обновлять языковые серверы
