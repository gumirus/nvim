## <span class="blue">mini.nvim</span>

- <span class="green">surround</span>: быстрое добавление/удаление/замена окружения (кавычки, скобки)
- <span class="green">comment</span>: комментирование строк (<kbd>gc</kbd>)
- <span class="green">pairs</span>: автозакрытие скобок
- <span class="green">move</span>: перемещение строк и блоков

## <span class="blue">noice.nvim + nvim-notify</span>

- <span class="green">Красивый UI для сообщений, команд, LSP</span>
- <span class="orange">Cmdline popup</span>: улучшенная командная строка

## <span class="blue">flash.nvim</span>

- <span class="green">Быстрый прыжок по тексту</span> (<kbd>s</kbd>, <kbd>S</kbd>, <kbd>r</kbd>)

## <span class="blue">better-escape.nvim</span>

- <span class="green">Мгновенный выход из insert-режима по <kbd>jk</kbd> или <kbd>jj</kbd></span>

## <span class="blue">nvim-ufo</span>

- <span class="green">Продвинутый folding с поддержкой LSP и Treesitter</span>

## <span class="blue">nvim-colorizer.lua</span>

- <span class="green">Подсветка цветов прямо в коде (hex/rgb/hsl)</span>

## <span class="blue">vim-illuminate</span>

- <span class="green">Подсвечивает все вхождения слова под курсором</span>

## <span class="blue">nvim-scrollbar</span>

- <span class="green">Красивая полоса прокрутки с индикацией поиска, ошибок и т.д.</span>

---

## <span class="red">Советы</span>

- Используй surround для быстрого редактирования кода
- Flash помогает мгновенно перемещаться по большим файлам
- Noice делает работу с командной строкой и LSP приятнее
