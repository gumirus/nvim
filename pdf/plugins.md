## <span class="red">Файловый менеджер</span>

### <span class="blue">nvim-tree</span>

- <span class="green">Горячая клавиша:</span> <kbd>Space</kbd> + <kbd>ee</kbd>
- <span class="orange">Описание:</span> Современный файловый менеджер для Neovim. Быстрый доступ к файлам, создание, удаление, перемещение.
- <span class="purple">Пример:</span> Открой файловый менеджер: <kbd>Space</kbd> + <kbd>ee</kbd>

---

## <span class="red">Git и работа с репозиториями</span>

### <span class="blue">gitsigns</span>

- <span class="green">Описание:</span> Показывает изменения в файлах (added, modified, deleted) прямо в редакторе.
- <span class="orange">Пример:</span> Перейти к следующему изменению: <kbd>]h</kbd>

### <span class="blue">lazygit</span>

- <span class="green">Горячая клавиша:</span> <kbd>Space</kbd> + <kbd>lg</kbd>
- <span class="orange">Описание:</span> Открывает мощный git-UI прямо в Neovim.
- <span class="purple">Пример:</span> Запусти lazygit: <kbd>Space</kbd> + <kbd>lg</kbd>
- <span class="blue">Подробнее:</span> [PDF: Работа с git](plugins-git.pdf)

---

## <span class="red">LSP и автодополнение</span>

### <span class="blue">mason.nvim</span>

- <span class="green">Описание:</span> Автоматическая установка LSP, форматтеров и линтеров.

### <span class="blue">nvim-lspconfig</span>

- <span class="green">Описание:</span> Настройка и запуск LSP-серверов.

### <span class="blue">nvim-cmp</span>

- <span class="green">Описание:</span> Современное автодополнение с поддержкой snippet'ов.

---

## <span class="red">Улучшение UX</span>

### <span class="blue">mini.nvim</span>

- <span class="green">Описание:</span> Минималистичные surround, comment, pairs, move.

### <span class="blue">noice.nvim + nvim-notify</span>

- <span class="green">Описание:</span> Красивый UI для сообщений, команд, LSP.

### <span class="blue">flash.nvim</span>

- <span class="green">Описание:</span> Быстрый прыжок по тексту (аналог easymotion/hop).
- <span class="purple">Пример:</span> Нажми <kbd>s</kbd> и введи букву для прыжка.

### <span class="blue">better-escape.nvim</span>

- <span class="green">Описание:</span> Быстрый выход из insert-режима по <kbd>jk</kbd> или <kbd>jj</kbd>.

### <span class="blue">nvim-ufo</span>

- <span class="green">Описание:</span> Продвинутый folding с поддержкой LSP и Treesitter.

### <span class="blue">nvim-colorizer.lua</span>

- <span class="green">Описание:</span> Подсветка цветов прямо в коде (hex/rgb/hsl).

### <span class="blue">vim-illuminate</span>

- <span class="green">Описание:</span> Подсвечивает все вхождения слова под курсором.

### <span class="blue">nvim-scrollbar</span>

- <span class="green">Описание:</span> Красивая полоса прокрутки с индикацией поиска, ошибок и т.д.
